# 评测报告规范（DOCX + PDF）

字体 STKaiti（楷体）；A4；结论先行；全篇统一评测对象数量口径；不写"应用户要求"式叙述腔，直接陈述事实；skill 名用官方全名。

## 章节结构

1. **封面**：大标题《N 款 PPT 生成 Skill 横向评测报告》+ 副标题（基准 · 双赛道 · 盲评张数）+ 基准封面缩略图 + 被评测对象名单（按最终名次）+ 执行署名（达仔 × ZCode (GLM-5.3-Flash) + 日期）
2. **目录**（手写条目式）
3. **摘要**：基准来源 → 双赛道定义 → 盲评方法（打散/盲码/张数/无遗漏）→ 终榜结论（加粗：每款名次+分数+推荐结论）
4. **第一章 评测背景与目标样例**：文章链接、采集方法、18 页拼接总览图、原稿特征（配色/密度/版式/页码章）、评测目标
5. **第二章 参赛 Skill 详述与安装方法**：2.0 选型理由（技术路线全覆盖/出品方与热度代表性/热度入围 + 落选说明）→ 每款按最终名次 2.1–2.N（定位、优劣、来源与安装）→ 资格裁定汇总表（原生形态/参赛形态/资格，转换与补全必须标注）
6. **第三章 评测设计与方法**：双赛道表、硬性规则（页数/可编辑/多模态）、评审口径（执行工具过程分仅参考；人工盲评为准）、排名口径
7. **第四章 评测流程**：Step 1–9（基准采集→就位→文字赛道→复刻赛道→渲染核验→执行工具评审→盲评工作台→人工盲评→揭盲统计）
8. **第五章 素材准备**：素材/规格/路径三列表
9. **第六章 测试内容**：两赛道说明 + 各 Skill 实际生成内容表
10. **第七章 测试结果**：7.1 排行榜柱状图 → 7.2 四象限图 → 7.3 打分矩阵总表 → 7.4 复刻赛道逐套详解（按名次）→ 7.5 文字赛道逐套详解 → 7.6 执行工具过程分（参考；必须写明"不可与盲评分直接比较"）
11. **第八章 缺陷台账**：评测工具误判（含修复）、产物缺陷表（含修复方式）、方法局限
12. **第九章 结论与推荐**：9.1 推荐名单（前三，含推荐理由与注意事项；上榜线说明）→ 9.2 不推荐名单（后三名，表格）→ 9.3 组合使用建议 → 9.4 一句话结论
13. **第十章 证据与复现索引**：证据/位置/说明三列表
14. **附录 全部成品 PPT 截图拼接总览**：每套一张 3×6 拼接图 + 标题（款名、赛道、盲码）

## 必含图表

- 图 1 基准 18 页拼接总览；图 2 双赛道分组柱状图（推荐线 2.5 金色虚线）；图 3 四象限定位图；图 4+ 过程分图（如适用）
- 所有分数 = 盲评实测均分（5 分制，两位小数）；套分 = 18 页平均；综合 = 两赛道平均

## 生成方式

复制 `scripts/report_template.py`（数据区按本次评测替换：名单、安装说明、分数表、逐套详解、拼图清单），`python report_template.py` 出 DOCX，再转换 PDF：
`soffice --headless --convert-to pdf --outdir <目录> <报告.docx>`
